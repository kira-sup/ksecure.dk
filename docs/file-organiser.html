File organiser

Turn a messy folder into documents, scripts and spreadsheets you can actually find.

THE SAMPLE RESULT5 sample files → 3 categories

The everyday problem

Downloads pile up quickly. Sorting the same kinds of files over and over is work a small script can handle.

What it does

Preview a sorting plan, then copy files into folders by type. Your original files stay where they are.

View sample output ↗

Try it yourself

Download and extract the bundle, install Python 3.10 or newer, then open a terminal in the extracted folder. No extra packages or API keys are needed.

py tools/sort_files.py samples/downloads output-downloads

This first command previews the plan. To copy the files, run:

py tools/sort_files.py samples/downloads output-downloads --apply
Download bundle ↓Setup help →

What goes in

A folder containing documents, scripts, images, archives or other files. The bundled sample includes nested folders and two different files with the same name.

What comes out

Categorised folders and a JSON log printed in the terminal. Different files with matching names get a numbered suffix. Copies are checked with SHA-256.

Technical details & limitations +

Copies files rather than moving them. Identical files with different names are not merged. Use trusted local folders, and run one instance at a time. An interrupted run can leave partial copies; originals remain available.

These examples were checked in Linux. Run them on sample data on your own computer before adapting them to real work.
