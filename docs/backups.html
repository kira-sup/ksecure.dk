Backup report

Turn an exported job list into a readable summary of successful runs and recent failures.

THE SAMPLE RESULT6 valid runs · 66.7% successful

The everyday problem

A long list of backup jobs makes it hard to see which machines need a closer look.

What it does

Validate exported runs, summarise successes and failures, and find the latest recorded result for each virtual machine.

View sample output ↗

Try it yourself

Download and extract the bundle, install Python 3.10 or newer, then open a terminal in the extracted folder. No extra packages or API keys are needed.

py tools/tables.py backups samples/backups.csv output-backups
Download bundle ↓Setup help →

What goes in

Columns: job_id, vm, started_at, status, duration_min, size_gb. Status is success or failed. Use ISO 8601 timestamps with a timezone, such as 2026-11-07T02:00:00+00:00.

What comes out

CSV details, an issues list, JSON summary and HTML report. The sample has 6 valid runs, 4 successes and 2 failures. The latest recorded job for dc-01 failed.

Technical details & limitations +

An export summary cannot prove a backup is restorable. It does not connect to Proxmox, find missing VMs, or check backup age. The success rate is per run. Duplicate job IDs are excluded after the first accepted record.

XLSX support: values on the first sheet only, with headers in row one. Formulas are rejected. Dates must be ISO text. CSV outputs are UTF-8 with BOM and can be imported in Excel. This tool does not create formatted XLSX workbooks.

These examples were checked in Linux. Run them on sample data on your own computer before adapting them to real work.
