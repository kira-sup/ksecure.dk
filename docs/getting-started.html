From download
to first result.

A short guide to running the projects on your own computer.

1. Get the files

Download the demo bundle and extract it completely. Keep the tools, samples and run_demo.py in the same folder structure. The original bundle includes the two original website concepts; this redesigned website is available in the GitHub repository.

2. Open the website examples

Double-click START_HERE.html in the extracted folder. The two original websites work without installing anything.

3. Run the automation examples

Install Python 3.10 or newer from python.org. On Windows, open PowerShell in the extracted folder and run:

py run_demo.py

On Linux or macOS, use python3 instead of py. The command runs all four script scenarios on bundled synthetic data. It creates a fresh folder inside runs/ and leaves the original samples available.

Open inventory/report.html and backups/report.html inside that new run folder to view the reports.

4. Explore one project at a time

The individual guides explain the input format, commands and results. The file tools preview a plan by default; --apply copies the files. Existing report folders are not overwritten, so choose a new output name for each run.

Excel and CSV compatibility +

The data tools accept UTF-8 CSV with commas, semicolons or tabs, and basic .xlsx files with values on the first sheet. Put the column names in row one. Input formulas are rejected. Dates must be ISO 8601 text with a timezone, not numeric Excel dates. Older .xls, macro-enabled .xlsm and encrypted workbooks are unsupported.

Outputs are CSV, JSON and HTML. In Excel, use Data → From Text/CSV and choose comma if the file appears in a single column. XLSX input is limited to 20 MB uncompressed; these demos load records into memory.

Check the scripts +

Run the included behaviour tests from the project folder:

py -m unittest discover -s tests -v

Nine tests cover copying, collisions, repeat runs, validation, report totals and minimal XLSX reading. Tests were run in Linux; Windows and desktop Excel still require local verification.

Something didn’t work? +

“py” not found: confirm Python is installed; try python or python3. Missing columns: compare your headers to the project guide. Output folder exists: use a fresh folder name. Formula in XLSX: paste values into a separate copy first. File-copy error: keep the original files, inspect the log and use a new output folder.

Know the scope

These are local learning tools and static websites. They use no AI API, do not connect to your servers and do not run Python inside the browser. The interactive homepage is a small JavaScript illustration using sample filenames.
