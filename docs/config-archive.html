Config archive

Keep configuration exports grouped by device and month, without sorting each one yourself.

THE SAMPLE RESULT3 valid exports → a dated archive

The everyday problem

When configuration exports are scattered across folders, finding the right device and date takes longer than it should.

What it does

Read the device name and date from each filename, validate the date, and copy matching exports into a consistent archive.

View sample output ↗

Try it yourself

Download and extract the bundle, install Python 3.10 or newer, then open a terminal in the extracted folder. No extra packages or API keys are needed.

py tools/sort_files.py samples/configs output-configs --mode configs

This first command previews the plan. To copy the files, run:

py tools/sort_files.py samples/configs output-configs --mode configs --apply
Download bundle ↓Setup help →

What goes in

Names such as sw01_2026-11-07.cfg or rb01_2026-11-07.rsc. Supported extensions: .cfg, .conf and .rsc. Device names use letters, numbers and hyphens.

What comes out

Folders such as sw01/2026-11/. The log identifies copied files and explains skipped names or invalid dates.

Technical details & limitations +

Does not connect to routers or switches. It organises exports you already have. Sample configurations are text illustrations, not configurations to install on hardware.

These examples were checked in Linux. Run them on sample data on your own computer before adapting them to real work.
