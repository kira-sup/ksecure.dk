Inventory cleaner

Clean up a device list and spot duplicate records, invalid addresses and conflicting IPs.

THE SAMPLE RESULT8 rows → 5 accepted records

The everyday problem

A spreadsheet is only useful when its records make sense. Extra spaces, duplicate entries and conflicting addresses are easy to miss.

What it does

Normalise device names, validate IP addresses and memory values, remove exact duplicates, and put issues in a separate review list.

View sample output ↗

Try it yourself

Download and extract the bundle, install Python 3.10 or newer, then open a terminal in the extracted folder. No extra packages or API keys are needed.

py tools/tables.py inventory samples/inventory.csv output-inventory
Download bundle ↓Setup help →

What goes in

CSV or a simple XLSX first sheet. Required columns: hostname, ip, role, ram_gb. Memory must be a positive number; IPv4 and IPv6 addresses are supported.

What comes out

clean.csv, issues.csv, summary.json and a readable report.html. In this sample, 8 input rows become 5 accepted records with 4 review notes.

Technical details & limitations +

IP conflicts are flagged but retained for human review. Review-note count is not rejected-row count. Total RAM adds inventory rows, including hosts and guests; it does not measure available physical memory.

XLSX support: values on the first sheet only, with headers in row one. Formulas are rejected. Dates must be ISO text. CSV outputs are UTF-8 with BOM and can be imported in Excel. This tool does not create formatted XLSX workbooks.

These examples were checked in Linux. Run them on sample data on your own computer before adapting them to real work.
