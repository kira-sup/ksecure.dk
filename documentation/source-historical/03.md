Summarises exported jobs and identifies virtual machines whose latest recorded run failed.</h2><p>`py tools/tables.py backups samples/backups.csv output-backups`</p><p>Required columns: job_id, vm, started_at, status, duration_min, size_gb. The topology is illustrative and status indicators are decorative, not live monitoring. Replace personal information only with details you can demonstrate.</h2><h2>06. IT service website
Open web/support.html. A light service-page concept with a process overview, expandable questions and a downloadable enquiry checklist. Run: `py -m unittest discover -s tests -v`</h2><p>Nine checks cover copying, collisions, repeat runs, dry-run behaviour, nested destination rejection, configuration filtering, report totals, invalid numbers, CSV escaping and minimal XLSX reading. Checks ran in Linux. Windows execution and desktop Excel need local verification.</p><p>If py is unavailable, confirm Python is installed and try python or python3.
